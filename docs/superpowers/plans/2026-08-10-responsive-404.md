# Responsive 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive, full-bleed 404 page centered on the existing wooden 404 artwork with clear home and catalogue recovery links.

**Architecture:** Keep `SiteShell` as the shared chrome and replace the 404 page's reusable `PageHero` usage with a page-specific scroll scene. Use a sticky visual stage with a responsive `<picture>`, independently scrolling content, CSS gradients for readable text, and `ButtonLink` for consistent CTA semantics.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, Playwright.

## Global Constraints

- Preserve the existing header, footer, skip link, analytics, and mobile quick actions.
- Keep the exact Vietnamese heading `Trang này không tồn tại`.
- Link CTAs to `/` and `/catalogue/`; do not retain the Zalo CTA on 404.
- Support 390x844, 430x932, 768x1024, 1024x768, 1280x800, and 1440x900 without horizontal overflow.
- Use existing assets only: `/images/404-desktop.webp` and `/images/404-mobile.webp`.
