# Catalogue LCP — Phase 7

**Chưa khắc phục.** Ba lượt lab mới: 10.812, 10.800, 10.796 ms; median **10.800 ms**, so với median Phase 6 **10.804 ms** (chênh −4 ms, không có ý nghĩa). Không có thay đổi tối ưu catalogue trong Phase 7; không kết luận CWV thực địa. `material-color-hero.webp` là LCP `<img>`, priority High; hero ~608.155 byte transfer, không có responsive source. Ảnh nguồn 1.916 × 821, 607.864 byte. Không tạo bản phái sinh vì chưa có xác nhận quyền.

Điều kiện: Chrome headless/Playwright, static export bản sao local, viewport 390×844 DPR 1, cache tắt, CDP download 1.600 kb/s, upload 750 kb/s, latency 150 ms, CPU 4×, analytics chặn, context mới mỗi lượt. TTFB 153,9 / 150,9 / 150,8 ms; CLS sau nhập 0,02124 mỗi lượt; long-task proxy (phần vượt 50 ms, không phải TBT) 61 / 15 / 18 ms. Tổng image transfer 1.791.665 / 1.791.656 / 1.791.671 byte; CSS 18.362 và JS 158.966 byte mỗi lượt. Khoảng request hero tới response end ~10,62 s; bằng chứng này không tách chính xác decode khỏi render, và không đo CDN production.
