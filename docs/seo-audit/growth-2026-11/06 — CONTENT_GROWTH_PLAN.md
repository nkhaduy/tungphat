# Content Growth Plan

## Working principle

Enrich the commercially useful pages already getting search exposure. Do not create a large batch of thin location pages, duplicate color pages or unverified spec sheets. Product/service claims must come from Tùng Phát CMS/data or manufacturer sources. Copy drafts follow the repository writing skill; draft metadata and text are in `03 — CTR_OPTIMIZATION_PLAN.md` and are not published.

## 1. Melamine An Cường — first priority

**Evidence:** latest live GSC table 10.287 impressions/57 clicks over 07/08–06/11 (CTR ≈0,55%); retained export 01/08–31/10: 9.013/53/0,59%, position 12,88. Query-filtered export showed broad color/map terms mostly positions 32–59, but covered only 1.286 impressions of 9.013; do not attribute every page click to those queries. Direct Google result sample shows the official page, image pack and AI Overview before Tùng Phát.

**Page capability already present:** 367 code links, an internal search field, supplier/material filters, code detail pages, Zalo/phone/quote links. Keep this function and code URLs. First visible area is text labels, not sample visuals.

**Work:** align title/H1/lead with “bảng màu” buyer wording; add selective verified swatches for codes with clicks/impressions; improve contrast between surface and board core; allow copying selected code and using it in an inquiry; link to relevant MDF/MFC and quote guidance. Limit image transfers; load below fold lazily; hold all exact code URLs/canonicals. First cohort can improve title/lead and imagery only after baseline capture.

## 2. Laminate collection

Live GSC table: 2.221/7 over the latest 3 months (CTR ≈0,32%); prior export 1.359/5/0,37%, position 18,34. At position ~18 historical, visibility/relevance is the first problem. Review intent and internal links, then test copy. Do not claim numbers of codes or offer variants unless current product data verifies them.

## 3. Gỗ ghép hub and branches

Live hub `/go-ghep/`: 171/14, CTR≈8,19%; previous export 150/13, position6,82. CMS verifies cao su and tràm; no verified current dimensions, grading, price, stock, lead time or species availability supplied in this audit.

Prioritize accurate first-party images of face/joint/edge; clarify which application/detail the buyer is asking about; provide a short quote checklist and link from material/CNC pages. For tràm, existing content has repetitive steps/FAQ noted in `release-2026-11-03/CONTENT_PROPOSALS.md`; rewrite duplicate answers before expanding. Do not add gỗ thông sales page absent business verification.

## 4. CNC service and guidance

CNC preparation article gets 254 impressions/11 clicks latest three months and 230/11 in prior export, historical position5,42. Keep this article as informational entry; link to the service page and quote checklist. Ask workshop to verify accepted file format, minimum details and actual operations before publishing specific workflow/turnaround claims. Measure submitted requests, not only clicks.

## 5. Catalogue quality cohorts

Current GSC live table confirms exact code demand for MS 852 T (27/82), plus supplier/color codes MS 530 NWM (7/365), MS 998 FR (8/144). Prior URL audit covers 2.652 sitemap URLs and notes many short catalogue records; short text count is a sampling signal, not Google quality threshold. Enrich code pages where exact-code clicks/impressions or first-party assets justify it. Keep URL when it already has demand. Prioritize:

- Exact codes with click history or visible query demand.
- Codes with licensed image/source and reliable product identity.
- Supplier/category collection pages that aggregate useful navigation.
- Real business leads, catalogue internal searches and backlinks when available.

Do not mass-noindex low-traffic codes or bulk-create descriptions. GSC tables are capped and query exports incomplete, so absence from the export is not proof of no demand.

## 6. Content evidence requirements

| Proposed content element | Required source before publishing |
|---|---|
| Stock, availability, price or discount | Current Tùng Phát product/CMS record or approved pricing source with valid date/conditions |
| Thickness, dimensions, grading, core, surface | Tùng Phát product data or exact manufacturer technical data |
| Certification, emissions, durability, moisture | Applicable manufacturer document and scope/date |
| Images/swatches | File-level source, license/use permission, supplier/code match and alt text |
| Business hours/location/branch | Business owner confirmation and matching contact/Maps record |
| CNC tolerance, minimum, throughput, delivery | Workshop process/policy owner confirmation |
