# SERP & Competitive Gaps

**Observed 08/11/2026.** The direct Google queries below were opened with `hl=vi&gl=VN`; Google footer resolved the location as Hồ Chí Minh “based on previous activity”. Results were personalized. Treat as a dated page sample, not a global rank tracker. Search result snippets and AI answers can change by user/location/time.

## Gỗ ghép cao su TP.HCM

- **Intent:** local buying, price/specification, likely inventory and size comparison.
- **Tùng Phát target:** `/go-ghep/`, then `/go-ghep-cao-su/`. Existing repository/CMS evidence verifies cao su and tràm routes; it does not verify current sizes, stock, grade or price.
- **Observed features/results:** AI Overview near top with claimed price/size detail and a citation to goghepphuongnam.com plus one source; Local Pack for a competing wood supplier; web results include goghepphuongnam.com, gominhtien.vn, goghep.com.vn, phuphugia.com, bathanhtaybac.com and gosaigon.vn; product surfaces visible lower down. Tùng Phát did not appear in the portion observed.
- **Gap:** visible competitors state locality, dimensions, grade/material and sometimes prices. Tùng Phát has not verified those commercial facts for this offering, so cannot safely match those claims yet. The live Tùng Phát page has a useful selection and quotation path but weak evidence of real stock/product variation in the first screen.
- **Differentiate:** first-party photos of actual cao su/tràm panels (surface, joint, edge); a verified list of available specs with date and “confirm before order”; plain quote checklist; direct Zalo/phone CTA. If the business has no verified specs, make the page useful by showing what buyers should send and how to distinguish cốt from surface.
- **Confidence:** high for observed SERP features and current competing URLs; medium for gap interpretation; low for actual rank outside the viewport.

## Bảng màu Melamine An Cường

- **Intent:** browse visual colors, find exact code/name, understand surface, then ask about material.
- **Target:** `/catalogue/an-cuong/melamine/`; live page has 367 linked code records and in-page search. Current H1/Title start with “Mã màu”, while query/result wording centers “Bảng màu”.
- **Observed features/results:** An Cường’s own page ranks first; Image pack immediately follows; a Google AI Overview appears and cites An Cường and Facebook sources; related search suggestions include “Catalogue Melamine An Cường”, “Map màu An Cường”, and exact color questions. Tùng Phát did not appear in the visible first page segment.
- **Competitors:** official An Cường provides current content and a direct map-color download; Hoàn Mỹ Decor, Tủ bếp Minh Long, ZEM Design and Thuận Phát appear in image/organic results. Third-party pages provide color groups, images, map downloads or exact-code tables. Their business claims are not evidence about Tùng Phát.
- **Gap:** exact code search is available locally, but the first-screen page is a grid of text code links without a visual swatch for each record. The metadata description only says “Tra cứu mã màu melamine của An Cường.” A code lookup result may not answer “what does the sample look like?”
- **Differentiate:** preserve exact code landing pages; test “Bảng màu…” wording; add a small set of licensed, verified thumbnail previews to valuable codes; offer copy/share code and quote CTA; disclose that displayed color is a screen reference and confirm substrate/spec when quoting. Do not generate 367 large thumbnails from unverified sources.
- **Confidence:** high for current SERP/browser, current HTML and GSC page exposure; medium for why click rate is low because query-page rows are incomplete.

## Ván MDF / MDF chống ẩm

- **Intent:** compare cốt, surface and application, find suppliers and specs.
- **Target:** `/van-mdf/`, `/mdf-chong-am/`, material guide `/tham-chieu-vat-lieu/`.
- **SERP research:** Google web search sample from web search results and manufacturer source search was not a direct localized browser capture. Do not claim exact ranks, AI features, Maps or shopping for this cluster.
- **Verified gap:** none of the current GSC live top 10 pages indicate an MDF category as a major CTR opportunity. Previous GSC Product snippets showed two impressions/zero clicks across the entire report; three family pages were flagged invalid Product items. Release changed them to CollectionPage. This is semantic correctness, not proof of ranking lift.
- **Action:** keep title stable while reading after release; prioritize manufacturer-backed specifications and clear distinction between core board and decorative surface. No offer/review/rating schema without genuine data.
- **Confidence:** medium on technical schema/history, low for current SERP features.

## CNC / cutting / edge banding

- **Intent:** “can you cut my file/material?”, file format/requirements, price, location and turnaround; local service choice.
- **Tùng Phát targets:** `/gia-cong-cnc/`, `/cat-cnc-go/`, `/bai-viet/chuan-bi-file-cnc/`, `/bao-gia/`. Services verified by repository writing source: panel cutting, CNC machining and edge banding. No throughput, tolerance, rush time or minimum order is confirmed here.
- **Search sample:** web search found competing service pages focused on location and process: Đông Á Decor has a Thủ Đức CNC page; IGAWOOD describes a stated minimum order; other local pages explain accepted file/spec information. These results are leads for further direct SERP checks, not objective rankings.
- **Gap:** the best differentiator is a transparent preflight checklist, accepted file format and fields to include in the quote request, based on actual workshop policy. Article `/bai-viet/chuan-bi-file-cnc/` already gets 254 impressions/11 clicks live in three months; link it to the service/quote path.
- **Action:** use the existing article as informational entry, show “file + material + thickness + quantity + dimensions” in service CTA, and measure completed requests. Avoid competing near-duplicate service pages until query × page shows their intent differs.
- **Confidence:** medium for the customer intent and existing content; low for current direct SERP placements.

## Supplier / exact code lookup

- **Intent:** direct lookup by exact code, color name or manufacturer.
- **Target:** `/catalogue/` and supplier/material/code hierarchy.
- **Evidence:** current live GSC page table shows MS 852 T at 27 clicks/82 impressions; homepage gets 64/1.167; An Cường Melamine collection gets 57/10.287. The visible exact-code snippets in GSC show demand but query-to-URL mapping is not available. One direct Melamine SERP shows official supplier content with a downloadable map, a large image pack and exact-code suggestions.
- **Gap/action:** promote search by code/name, link high-intent codes from collection, keep manufacturer and code labels consistent, preserve code-specific URLs that have clicks. Do not consolidate/redirect exact-code pages into collections.
